# Changelog

## 1.0.0 — Integrated application

- Combines candidate exploration, range-file creation, and isotope-overlap
  analysis in a native macOS application.
- Includes the available Python, notebook, HTML, and template resources.
- Uses project JSON files to exchange selections, spectra, and ranges.
- Provides candidate, range-file, and analysis-table export workflows.

The integrated application has its own version sequence. The bundled Spectrum
Analyser notebook and Range File Maker may display different module versions.
No public release date is asserted by this preparation folder.
