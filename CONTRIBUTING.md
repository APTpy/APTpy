# Contributing to APTpy

Feedback, tests on new datasets, documentation improvements, and code contributions
are welcome.

## Report an issue

Include the app/module version, macOS version and hardware, steps to reproduce,
expected behavior, actual behavior, and relevant log excerpts. Logs from the main
app are stored under `~/Library/Logs/APTpy/`. Remove private data and local paths
before sharing logs. Small synthetic examples are preferred for public reports.

## Scientific changes

For new ion candidates, provide a publication reference, the exact source
location, reported charge states, and any ambiguity or experimental conditions.
Distinguish reported observations from tentative alternatives. For changes to
ranging or isotope fitting, describe the assumptions and provide a reproducible
example demonstrating the effect.

## Code contributions

Work on a branch, explain the change, and include appropriate verification.
Preserve existing attribution and license notices. Contributions intended for
inclusion in this project are submitted under GPL-3.0-or-later.

Do not commit experimental EPOS/POS files, private project JSON, credentials,
Python environments, or generated app archives. Distribute application binaries
as release assets.
