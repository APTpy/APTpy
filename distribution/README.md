# Local distribution files

This folder holds the unchanged copy of `APTpy V1.0.0.app`, its downloadable ZIP,
and a SHA-256 checksum. These binary assets are excluded from Git tracking.
Attach the ZIP and checksum to a GitHub Release when the app is ready to publish.

The app uses external, machine-specific Python paths. Read
`../docs/INSTALLATION.md` before sharing it as a general download.
